# Frontend/indoor-outdoor/

Placeholder for **Indoor ⇄ Outdoor** mode logic — the branch that swaps data
source, basemap / floor-plan, and environment model (indoor = controlled
conditions; outdoor = path loss affected by traffic / atmosphere).

Today everything is Indoor: the walk data in [../../Data/](../../Data/) and the
viewer in [../2d-3d/](../2d-3d/). The Outdoor counterpart currently lives in the
separate `Outdoor_Walk_Test_7-24` project; unifying them is a future task.
