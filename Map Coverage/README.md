# Map Coverage

Map Coverage tab assets for the dashboard shell (`Frontend_Data_Display.html`).

| File | Role |
|------|------|
| `dashboard.js` / `dashboard.css` | Indoor Map Coverage + Statistics + Time Elapse shell logic |
| `viewer3d.js` | 3D CAD Map Coverage (three.js) |
| `georef.js` | Floor-plan georeference helpers |
| `outdoor_view.html` | Outdoor Map Coverage iframe (Leaflet 2D / three.js 3D) |
| `osm_buildings_view.html` | Legacy OSM buildings experiment |

Walk / basemap payloads live under `Data + Model/` (compat symlink: `Data/`).
